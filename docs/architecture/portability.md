# Portability

現在の正式な入口はCodexの `AGENTS.md` と `.agents/skills`。文書・作業記録は通常のMarkdownとして保つ。

- 他ツール用の `CLAUDE.md`、`.claude`、互換アダプター、推測した設定は現時点で作らない。
- SOUL / IDENTITY / USER / TOOLS / MEMORYやworkはリポジトリの運用規約。どのAIでも自動認識されるとは仮定しない。
- パスは文書内では相対参照を優先し、個人端末の絶対パス・秘密値を埋め込まない。
- Tool名・モデル版・ログイン状態を一般規則の必須条件にしない。

別ツールを実際に使うときは、その時点の公式仕様で指示の探索・優先順位・Skill形式・権限を確認する。正本は維持し、必要な最小限の入口だけを作成・検証する。移行理由・参照元・検証結果はADRへ記録する。
