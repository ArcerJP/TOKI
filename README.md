# TOKI

参加可能時間を共同編集するガントチャート。HTML・CSS・JavaScriptは別ファイルです。

## 共有して使う

1. 管理者から届いた **`#share=…`を含む共有URL** を開きます。
2. 最初に表示名を入力すると、新しい行を末尾に追加します。
3. 同名がある場合は警告します。苗字やニックネームを加えて別の名前にしてください。既存の行を自動で引き継ぎません。
4. 同じ端末・ブラウザーでは参加状態を記憶し、次回の名前入力を省略します。

メール・パスワード・アカウント登録は不要です。共有URLを知っている人は、全員の予定を閲覧・編集できます。名前は本人確認には使いません。別の端末やブラウザーでは別名で参加してください。ブラウザーの保存データを消すと参加状態は失われますが、共有の予定は残ります。

サイトの入口は https://arcerjp.github.io/TOKI/ です。初めて開く際は、末尾まで含む共有URLが必要です。参加後の「共有URLをコピー」で同じURLを配布できます。共有URLは公開リポジトリに載せないでください。

## 操作

- 日付のプルダウンで2026年10月3日〜8日を切り替え
- 空き枠をドラッグして追加、予定をドラッグして移動、両端をドラッグして時間変更
- 予定をクリックしてタイトル・詳細・名前・日付・時刻を編集
- 元に戻す：Ctrl/Cmd+Z、やり直す：Ctrl/Cmd+Shift+Z
- PDF出力：表示中の1日または全6日を選び、印刷画面で「PDFに保存」（A3横向き推奨）

表示範囲は8:00〜24:00、目盛りは30分刻み。時刻は1分単位で入力できます。参加者は最大100人。人数に応じて行・人数表示・PDFが変わります。

変更はSupabaseに保存し、画面表示中は約5秒ごとに同期します。同じ版を同時編集した場合、後から保存する側に警告し、先の変更を上書きしません。その場合は編集画面を閉じて最新の予定を確認し、再度編集してください。他の人の更新を反映すると取り消し履歴をクリアします。通信失敗時は保存済みと表示しません。

## 端末内で使う

`index.html`を直接開くか、`node serve.cjs`で http://127.0.0.1:4173 を開きます。端末内モードは共有版と別のデータです。共有版をlocalhostで確認する場合は`?mode=shared#share=…`を付けてください。

公開用`data.js`は「メンバー1〜16」と空の予定です。実際の初期予定はGit管理対象外の`data.local.js`に保存し、端末内モードでだけ読み込みます。端末内モードの編集はブラウザーの保存データを消すと失われます。

## 管理・開発

```sh
npm ci --ignore-scripts
npm run build
npm test
```

`database/schema.sql`をSupabase SQL Editorで実行します。旧ログイン方式からの移行にも対応し、元の予定を保持します。新規環境では別途、`public.toki_boards`に初期データを登録してください。スキーマには個人の名前・予定・共有トークンを含みません。

共有URLには暗号学的乱数32バイトを16進数にしたトークンを使用します。管理者が生成したトークンのSHA-256だけを`toki_private.share_links`に登録します。ブラウザーはURLのフラグメントからトークンを読み取り、RPCのPOST本文でSupabaseに送信します。公開APIキーだけでは予定にアクセスできません。テーブル直接アクセスは無効で、専用RPCが共有トークン・入力・版番号を検証します。同名の確認と行追加はDBでロックし、同時登録による重複も防ぎます。全角・半角、英字の大文字・小文字、前後の空白を正規化して比較します。

接続先・公開可能なキーは`config.js`に設定します。Secret keyやservice_roleは使用しません。`vendor/supabase.js`は固定バージョンの公式クライアントです。共有トークンを変更すると旧URLは使えなくなるため、変更する場合は新しいURLを参加者に配布してください。

`main`へのPushでGitHub ActionsがGitHub Pagesに公開します。公開対象は指定されたHTML・CSS・JavaScriptのみです。DBスキーマの変更は自動適用されません。個人データ・共有URL・PDF・画像・秘密鍵・`tmp/`はコミットしないでください。

テスト：名前重複の拒否、端末の参加状態復元、同時編集の競合、無効な共有URLの拒否、通信失敗時の処理、公開データへの個人情報の混入防止。
