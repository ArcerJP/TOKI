# TOKI

可能時間を人・グループ別に共同編集するガントチャート。HTML・CSS・JavaScriptは別ファイルです。

## 開く・共有する

管理者から届いた`#share=…`まで含む共有URLを開くと、名前入力なしで予定表を表示します。メール・パスワード・アカウント登録は不要です。URLを知る人は全員分の予定・人・グループを編集できます。「共有URLをコピー」で同じURLを配布できます。

入口は https://arcerjp.github.io/TOKI/ です。初回は共有URLが必要です。同じブラウザーでは共有先を記憶します。共有URLは公開リポジトリには掲載しないでください。

## 人・グループ

- 人の追加：上部の「＋ 人を追加」、または表の最終行の下にカーソルを合わせて表示される「＋ 人を追加」。タッチ端末では常時表示します。
- 人の編集・削除：左列の名前をクリック。削除は確認後に実行し、その人の予定と全グループへの所属も削除します。
- グループの追加：「＋ グループを追加」でグループ名と所属する人を選択。
- 所属の変更：人・グループの編集画面でチェック。1人が複数のグループに所属できます。
- 行のドラッグ：名前の左の「⋮⋮」をつかみ、人の行の上／下へドロップして並べ替え。グループ内の並び順も保存します。
- グループの並べ替え：グループ名の左の「⋮⋮」をつかみ、別グループの上／下へドロップ。所属する人とグループの予定を保ったまま、グループ単位で移動します。上下キーと「元に戻す」も使えます。
- グループへの配属：グループの見出し、またはそのグループ内の人の行へドロップ。元の所属は残し、所属先を追加します。
- グループからの除外：所属中の行を未所属の人の行、または表の末尾の「＋ 人を追加」の行へドロップ。ドラッグ元のグループへの所属だけを解除し、ほかの所属と予定は残します。
- ほかの所属が残っている人は、そのグループ内に表示されます。所属がなくなった人は、ドロップした位置に未所属の行として表示されます。
- ドラッグはEscでキャンセル。移動後は「元に戻す」で復元できます。「⋮⋮」にフォーカスして上下キーを押すと、同じグループ内／未所属内で並べ替えできます。
- 折りたたみ・展開：グループ名の左の矢印。グループ自体の予定は折りたたみ中も表示します。
- グループの削除：グループ名をクリックして削除。そのグループのMTGを解除し、対象者の可能時間を復元します。人は残ります。

個人の予定は、どのグループ内から編集しても同じ内容になります。グループ行には対象者全員の共通時間を自動表示します。各人の変更は、その人が所属する全グループへ反映します。どのグループにも所属しない人は、グループの下に並びます。同名の人・同名のグループは追加できません。人は最大100人、グループは最大50個です。

## 予定・PDF

- 表内右上の全画面アイコンで、日付・編集ボタンを残して予定表を大きく表示。「全画面終了」またはEscで戻ります。全画面API非対応のブラウザーでは、ブラウザー内いっぱいに表示します。
- 「💡ヒント」を押すと、編集・並べ替え・グループ・予定の操作説明を箇条書きで表示します。
- 日付のプルダウンには、選択中の週の日曜〜土曜の7日間を表示
- 「‹」「›」で前日・翌日へ移動。週の境界をまたぐとプルダウンも切り替え
- 「≪」「≫」で前週・翌週の同じ曜日へ移動。月・年をまたいで、ほかの週にも予定を保存可能
- 個人の空き枠をクリックで30分追加、ドラッグで範囲を追加。既存の帯のクリックだけでは変更しません。
- 個人の可能時間はドラッグで移動、両端で伸縮。開始と終了を重ねて離すと削除します。タイトル・詳細・時刻入力の画面はありません。
- 個人の可能時間を約0.6秒長押しすると「削除」「時間をコピー」を表示。「削除」は押した帯全体を削除し、所属する各グループの共通時間にも反映します。「時間をコピー」は押した帯だけを「10月5日(月)：09:00～10:00」の形式でコピーします。右クリック・Shift+F10にも対応。ドラッグすると長押しを取り消します。オフライン時はコピーのみ利用できます。
- 人の横の✓でグループの対象から一時除外。名前に取り消し線を表示し、その端末だけで共通時間の計算・新規MTGの対象から外します。登録済みMTGの対象者は変えません。
- グループの可能時間上をクリックすると、その30分枠をMTGへ変換。ドラッグすると選択範囲をMTGへ変換し、対象者の個人の可能時間から除きます。可能時間の途中にもMTGを入れられます。
- グループの可能時間がない場所や、可能時間から一部でもはみ出す選択は「⚠️可能時間がありません」と表示し、登録しません。
- グループの可能時間は、両端を縮めて減らした部分をMTGにする操作もできます。可能時間自体の追加・延長・移動はできません。
- MTGの色はグループごとに自動決定。グループ行は対象者名、個人行はグループ名を表示します。
- グループ行のMTGは、両端をドラッグで拡張・短縮、帯の中央をドラッグで長さを保って同じ日の同じグループ内を移動。登録済みの対象者全員の可能時間で判定し、元のMTG時間も利用できます。一時除外や所属の変更後も、登録済みの対象者を維持します。
- MTGの調整で空いた部分は対象者へ復元し、新たに使う部分を対象者の可能時間から除きます。誰かの可能時間がない部分や別のMTGに重なる変更は「⚠️可能時間がありません」と表示し、変更を取り消します。長さゼロで全体を解除。グループ行のMTGをクリックし、対象者の✖で一人だけ解除・復元する操作も維持します。
- MTG帯を約0.6秒長押しすると操作メニューを表示。グループの「削除」はそのMTGの対象者全員、個人の「削除」はその人だけの可能時間を復元し、グループの表示にも反映します。ドラッグを始めると長押しを取り消します。右クリック、帯にフォーカスしてShift+F10でも開けます。
- グループの長押しメニューの「時間をコピー」は、そのMTGだけを「10月5日(月)：09:00～10:00」の形式でコピーします。
- 個人の追加・延長やGoogle取込は、参加中のMTGと重なる部分を除外します。グループからの脱退は既存MTGに影響しません。
- 「可能時間書き出し」で人・グループと開始日・終了日を指定し、テキストをコピー。可能時間がない日は「なし」。グループは一時除外した人を除く共通時間です。
- 元に戻す：Ctrl/Cmd+Z、やり直す：Ctrl/Cmd+Shift+Z。人・グループの削除も復元可能
- PDF出力：表示中の1日または表示中の週（日曜〜土曜の7日間）を選び、印刷画面で「PDFに保存」（A3横向き推奨）

PDFではグループをすべて展開し、個人・グループ双方の予定を出力します。表示範囲は8:00〜24:00、目盛りは30分刻み。新しい時間は30分単位で操作します。移行前の12:50などの時刻は保持します。

変更はSupabaseに保存し、画面表示中は約5秒ごとに同期します。同じ版を同時編集した場合、後から保存する側に警告し、先の変更を上書きしません。編集画面を閉じ、最新の内容を確認してから再編集してください。他の人の更新を反映すると、取り消し履歴をクリアします。折りたたみ状態はブラウザーごとに保存します。

## 端末内で使う

`index.html`を直接開くか、`node serve.cjs`で http://127.0.0.1:4173 を開きます。端末内モードは共有版とは別のデータです。共有版をlocalhostで確認する場合は`?mode=shared#share=…`を付けます。

公開用`data.js`は「メンバー1〜16」と空の予定です。実際の初期予定はGit管理対象外の`data.local.js`に分離し、端末内モードでだけ読み込みます。端末内モードの編集はブラウザーの保存データを消すと失われます。共有データは消えません。

## Googleカレンダーから可能時間を取り込む

任意のGoogleログインで、メインカレンダーの指定期間から空き時間を取り込めます。FreeBusy APIと`calendar.freebusy`権限のみを使用し、予定のタイトルや詳細は取得しません。30分枠に少しでもBusy区間が重なれば除外します（11:10〜11:50の予定なら11:00〜12:00を除外）。時刻は日本時間、表と同じ毎日8:00〜24:00が対象です。

取り込み先の人・開始・終了を指定し、プレビューを確認してから、その人の指定期間を置き換えます。期間外の可能時間・他の人・MTGは保持します。MTGと重なる時間は除外し、グループの共通時間も再計算します。「元に戻す」にも対応しています。

利用開始には`config.js`の`googleClientId`設定が必要です。クライアントID未設定時は画面に準備中と表示し、ログインを開始しません。[Google側の設定手順と取り込み仕様](docs/google-calendar-setup.md)を参照してください。

## PWA・オフライン

- アプリ名は「TOKI」、起動は独立したウィンドウ（`standalone`）。192px / 512px・マスク可能アイコンとApple用アイコンを同梱しています。
- 対応するChrome / Edgeでは「アプリをインストール」ボタンまたはブラウザーのインストールメニューを使用します。iPhone / iPadでは共有メニューの「ホーム画面に追加」を使用します。表示される操作は端末・ブラウザーによって異なります。
- 最初はオンラインで共有URLを開いてください。確認済みの共有URLを同じブラウザー内に記憶し、アプリの起動時にも使います。別のブラウザーや、保存領域が分かれている環境では、共有URLをもう一度開いてください。
- 一度取得した画面のファイルと共有予定を端末に保存します。オフラインでは最後に取得した可能時間・MTGを閲覧でき、日付変更・グループ展開・PDF出力も利用できます。最終取得時刻を表示し、共有予定の編集・並べ替え・保存は停止します。オフライン編集の送信待ちは作りません。
- 接続が戻ると予定を再取得し、編集を再開できます。端末に未保存の初回アクセスでは、オフライン閲覧はできません。端末内モードのローカル編集は引き続き利用できます。
- 同じ端末・ブラウザーを使用できる人は、保存済みの共有予定を閲覧できます。削除する場合はブラウザーのこのサイトのデータを削除してください（端末内モードの予定や記憶した共有URLも削除されます）。
- Service Workerは公開ファイルの許可リストだけをキャッシュし、Supabaseへの通信・`data.local.js`・秘密ファイルをキャッシュしません。予定のスナップショットは共有URLごとに照合したうえで読み込みます。
- 画面更新時は「最新版に更新」が表示されます。編集を保存・終了してから押してください。他のタブの編集を勝手に再読み込みすることはありません。

`node scripts/prepare-site.cjs`で公開用の`site/`を生成します（既存の`site/`は再生成）。全公開ファイルの内容からキャッシュの版番号を自動生成するため、変更時に版番号を手作業で更新する必要はありません。GitHub Actionsも同じ処理を使います。`sw.js`はテンプレートなので、公開時は生成済みの`site/sw.js`を使います。ローカルでは`node serve.cjs`が生成済みService Workerを配信します。`file://`で直接開く場合はPWA機能を利用できません。

実装の参照：[MDN・インストール可能なPWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)、[MDN・Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)。

## 管理・開発

```sh
npm ci --ignore-scripts
npm run build
npm test
```

`database/schema.sql`をSupabase SQL Editorで実行します。schemaVersion: 4へ一度だけ自動変換し、人・所属グループ・個人の全時間帯を維持します。タイトル・詳細と独立した旧グループ予定は削除し、グループの可能時間を個人の共通時間から計算します。バックアップは作成しません。MTGは固定対象者を持つ別レコードとして保存します。保存は`save_availability`、読込は`read_availability`です。旧画面はPWA更新のため読み込みだけ許可し、旧保存処理は拒否します。SQLは再実行しても新方式のMTGを削除しません。

共有URLには暗号学的乱数32バイトを16進数にしたトークンを使い、DBにはそのSHA-256だけを保存します。テーブルへの直接アクセスは無効です。専用RPCが共有トークン・名前重複・予定の対象・所属メンバー・版番号を検証します。公開APIキーだけでは予定を取得できません。Secret keyやservice_roleは使用しません。

`model.js`は人・所属・MTG対象者の参照検証、`availability.js`は時間区間の計算、`schedule.js`はMTG予約・復元とコピー文字列を扱います。保存・取り消しは人・グループ・予定をまとめて処理するため、削除・復元で参照がずれません。

`main`へのPushでGitHub Actionsが指定された静的ファイルだけをGitHub Pagesに公開します。DBスキーマは自動適用されません。個人データ・共有URL・PDF・画像・秘密鍵・`tmp/`はコミットしないでください。
