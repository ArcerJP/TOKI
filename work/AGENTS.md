# Work guidance

- 状態とリスクの定義は [WORKFLOW.md](WORKFLOW.md) を必要なときに読む。
- task folderの所在とrequestのstatusを揃える。状態変更はコピーではなく移動。
- 実装は実際のソースを編集し、workにアプリのコピーを置かない。
- Researchは調査、Planは予定、Handoffは検証済み結果。現行仕様はdocsへ必要な内容だけ反映。
- 動的な作業記録は非公開が初期値。ユーザー依頼・認証情報・本番データをGitやPRへ自動転載しない。
- 完了と確認待ちを区別する。人の確認前にarchiveへ移さない。
