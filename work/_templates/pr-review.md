# PR review

## Scope Match

解決する問題、承認範囲、関係のない差分の有無。

## Correctness

仕様と実装の整合、境界条件、回帰。

## Findings

重要度・ファイル位置・根拠・影響。推測や未確認を区別。

## Tests

実施したチェック、結果、未実施事項。実装をなぞるだけのテストで結論を出さない。

## Security

権限、会社間の分離、公開物、秘密・個人情報の混入。該当しない項目は簡潔に記す。

## Documentation

正式仕様・ADR・索引の更新状況。

## Compatibility

既存動作、データ、環境との互換性。

## Unintended Changes

依頼と関係のない差分や生成物の有無。

## Result

修正が必要か、確認待ちか、残るリスク。実際の人の承認を代行しない。
